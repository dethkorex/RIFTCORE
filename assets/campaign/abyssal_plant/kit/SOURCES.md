# Abyssal Plant kit

* `industrial_pipes.glb`: **Modular Industrial Pipes 01**, Poly Haven, CC0 1.0.
  Source: https://polyhaven.com/a/modular_industrial_pipes_01
  License: https://polyhaven.com/license
  Downloaded official 1K glTF with MD5 verification; textures resized to 512px,
  packed once for shared use. Original geometry retained.
* `discharge.gdshader`: original volumetric mesh shading with value-noise/hash
  adapted from Loop_Box's **3D Lightning shader**, based on FencerDevLog, CC0.
  https://godotshaders.com/shader/3d-lightning-shader/
  We build real branching tube geometry; this is not the reference's flat plane.
* Remaining GLBs: Riftcore original mechanical kit. Reproducible Blender source:
  `distribution/build_abyssal_kit.py`. Separate shroud/rotor and lock/slab meshes.
* `water.gdshader`, `sea.gdshader`, gameplay/mesh effects: Riftcore original.

No paid pack, Tripo generation or new sound pack used. Compatible with the
Windows/Linux GL Compatibility renderer. Uses the existing Riftcore sound bank.
