# Neon Factory enemy models

The active factory robot kit uses original Godot scenes. The cargo crate uses the loot box by Quaternius from the [Cyberpunk Game Kit](https://quaternius.com/packs/cyberpunkgamekit.html), supplied under CC0 1.0. The archived robot imports came from this kit and the [Sci-Fi Essentials Kit](https://quaternius.com/packs/scifiessentialskit.html), also supplied under CC0 1.0.
