# RIFTCORE Alpha 6.3.45

## Profile progression
- Mission clears now award half the Profile XP they paid before Alpha 6.3.44. A Normal Ember Foundry clear gives 88 Profile XP, down from 257 in Alpha 6.3.44.
- Existing Profile XP is preserved. Operator XP, Core Shard rewards, and Core Ascension prices stay the same.
