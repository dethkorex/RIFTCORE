# RIFTCORE Alpha 6.3.26

- Launcher 0.3 checks for new builds and starts downloading immediately. Play becomes available once installation finishes. If you are offline, you can play an installed build.
- Existing Launcher 0.2 users can choose Update and Play to upgrade in place. Your current installer shortcut and saved progress carry over.
- New Windows and Linux installers contain the launcher and fetch the newest build on first launch. The Arch portable download still includes the game.
- The updater supports game downloads up to 1 GiB.

Open RIFTCORE from your existing launcher shortcut. In-game updates are available under Settings → Update Game.
