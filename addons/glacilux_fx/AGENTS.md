# GLACILUX - notes for coding assistants

Free Ice Lance VFX for Godot 4 (the free Lite edition), version 1.0.1, by gennai. Generated by `tools/vfxpack/make_catalog.py` from the addon
source; `catalog.json` next to this file carries the same facts as data (every exported
property with type and default, every public method signature, every preset's values).

- Addon folder: `res://addons/glacilux_fx/`. Nothing outside it is needed at runtime. There is no plugin to
  enable, no autoload, no project setting and no input action: every node is a `class_name`.
- Godot 4.4 or newer; tested on 4.4.1, 4.5.2, 4.6.3 and 4.7.2, on Forward+, Mobile and Compatibility. Web exports work.
- Every class name starts with `Glacilux`. Effects are nodes; their geometry lives in internal child
  nodes that are never saved into the scene, so do not reach into an effect's children.
- No textures, no imported meshes, no `GPUParticles`, no `Decal`, no compute shaders: every
  element is a static mesh moved by its vertex shader, so element counts are cheap.
- Presets: 2 scenes under `presets/` whose root is one of the nodes below with the listed
  values changed. Instantiate one, or `Glacilux.spawn(parent, "<name>", position)`.
- This is the free Lite edition; the full pack (https://gennai.itch.io/ice-frost-vfx-godot-4) has the other nodes and presets.

## Calls from the README

```gdscript
Glacilux.spawn(self, "impact_shards", hit.position)
```

## Renderer caveats and known limitations

- Shards, icicles and wall debris bounce on one ground height only; they do not collide with each other or with other objects.

## When writing code against this pack

- Drive an effect through its public methods and exported properties only.
- One-shots (`is_one_shot()` true) play with `trigger()` and emit `finished`; looping effects
  start with `play()` or their own start method and stop with `stop()`, fading over `fade_time`.
- `Glacilux.spawn()` sets `free_when_done`, so a spawned node frees itself; keep a reference and
  call `stop()` on a looping one.
- `Glacilux.warmup(camera)` behind a loading screen builds every preset once so the shaders are
  compiled before the first real effect (Compatibility links a shader on its first draw).
- `Glacilux.quality` (LOW / MEDIUM / HIGH) scales element counts globally; a node's own `quality`
  overrides it.
- Scaling the node scales the whole effect. Defaults here are the class defaults; a preset's
  listed values override them.
