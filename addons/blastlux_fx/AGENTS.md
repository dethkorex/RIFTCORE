# BLASTLUX - notes for coding assistants

Free Shockwave VFX for Godot 4 (the free Lite edition), version 1.0, by gennai. Generated by `tools/vfxpack/make_catalog.py` from the addon
source; `catalog.json` next to this file carries the same facts as data (every exported
property with type and default, every public method signature, every preset's values).

- Addon folder: `res://addons/blastlux_fx/`. Nothing outside it is needed at runtime. There is no plugin to
  enable, no autoload, no project setting and no input action: every node is a `class_name`.
- Godot 4.4 or newer; tested on 4.4.1 and 4.7.2, on Forward+, Mobile and Compatibility. Web exports work.
- Every class name starts with `Blastlux`. Effects are nodes; their geometry lives in internal child
  nodes that are never saved into the scene, so do not reach into an effect's children.
- No textures, no imported meshes, no `GPUParticles`, no `Decal`, no compute shaders: every
  element is a static mesh moved by its vertex shader, so element counts are cheap.
- Presets: 3 scenes under `presets/` whose root is one of the nodes below with the listed
  values changed. Instantiate one, or `Blastlux.spawn(parent, "<name>", position)`.
- This is the free Lite edition; the full pack (https://gennai.itch.io/explosion-vfx-godot-4) has the other nodes and presets.

## Calls from the README

```gdscript
Blastlux.spawn(self, "shockwave_dust_ring", point)
var wave := BlastluxShockwave3D.new()
add_child(wave)
wave.wave_at(point, 6.0)
```

## Nodes

| Class | Extends | File | What it is |
|---|---|---|---|
| `Blastlux` | `RefCounted` | `core/blastlux.gd` | Global settings and the one-line helpers of BLASTLUX. |
| `BlastluxEffect3D` | `Node3D` | `core/blastlux_effect_3d.gd` | Base of every BLASTLUX 3D effect: the clock, one-shot bursts, fading, the palette, wind, the dynamic light and the layer list (one MeshInstance3D + ShaderMaterial per layer). |
| `BlastluxPalette` | `Resource` | `core/blastlux_palette.gd` | Colours of one blast family. |
| `BlastluxShockwave3D` | `BlastluxEffect3D` | `nodes_3d/blastlux_shockwave_3d.gd` | The wave on its own: a dust ring racing over the ground, a translucent pressure disc that stands up through the air, and a heat ripple that bends what is behind it (Forward+ and Mobile; Compatibility shows the ring and the disc). |

## Presets

Bare names for `Blastlux.spawn()`; `catalog.json` lists the values each one sets.

- `BlastluxShockwave3D`: `shockwave_dust_ring`, `shockwave_heat_ripple`, `shockwave_pressure_disc`

## Renderer caveats and known limitations

- The heat ripple (`ripple` on `BlastluxShockwave3D` and `BlastluxShockwave2D`) reads the screen texture and is not drawn on the Compatibility renderer; the ring and the disc carry the wave there.

## When writing code against this pack

- Drive an effect through its public methods and exported properties only.
- `Blastlux.spawn(parent, "shockwave_dust_ring", point)` sends a wave from `point`; `BlastluxShockwave3D.wave_at(point, radius)` does the same on a node you keep.
- The heat ripple reads the screen texture and is not drawn on the Compatibility renderer; the ring and the disc are.
- `Blastlux.quality` (LOW / MEDIUM / HIGH) scales the dust count; `Blastlux.wind` drifts the dust.
- Scaling the node scales the whole effect. Defaults here are the class defaults; a preset's
  listed values override them.
